================================================================================
          STM32 -> ESP32 (UART2) 通信协议 —— 解帧指南
================================================================================

一、帧总体格式
────────────────────────────────────────────────────────────
  AA 55 | Length_L Length_H | Type | Seq | Timestamp | Payload | CRC_L CRC_H | 0D 0A
  2字节   2字节              1字节  1字节   4字节      N字节     2字节         2字节
────────────────────────────────────────────────────────────

  字段      大小    说明
  ─────     ────    ──────────────────────────────────────
  帧头      2B      固定 0xAA 0x55，用于找帧起始
  Length    2B      小端序，= 1(Type) + 1(Seq) + 4(Timestamp) + N(Payload) + 2(CRC)
  Type      1B      数据类型: 1=瞬时速度, 2=总脉冲, 3=IMU, 4=雷达
  Seq       1B      序号，每种Type独立从0递增(溢出回绕)
  Timestamp 4B      时间戳，uint32_t，小端序，数据就绪瞬间打上的HAL_GetTick()毫秒数
  Payload   NB      载荷数据，按Type不同结构不同(见下文)
  CRC16     2B      Modbus CRC16，小端序(低字节在前)
  帧尾      2B      固定 0x0D 0x0A，用于确认帧结束

  Timestamp 说明:
    - 在数据就绪的瞬间由调用方调用 HAL_GetTick() 获取，而非组帧发送时
    - IMU/LiDAR: data_ready 为真的瞬间打戳
    - 速度/脉冲: PID周期读取编码器数据的瞬间打戳
    - 开机后经过的毫秒数，约49.7天溢出回绕一次
    - 用于上层建图时对齐不同传感器数据的时间基准

  Length 为2字节小端序，支持最大65535字节帧体，
  可完整传输雷达全量数据(512点 = 4098字节Payload)。

  CRC16 计算范围: 从 Length 字段开始，到 Payload 末尾结束
                 (帧头 AA 55 和帧尾 0D 0A 不参与CRC计算)

  CRC16 算法: Modbus标准
    初始值 = 0xFFFF
    对每个字节:
      crc ^= byte
      循环8次:
        if (crc & 1)  crc = (crc >> 1) ^ 0xA001
        else          crc >>= 1


二、解帧步骤
────────────────────────────────────────────────────────────

  1. 找帧头: 在字节流中搜索 0xAA 0x55
  2. 读Length: 下两个字节，小端序 uint16_t
  3. 计算Payload长度: payload_len = Length - 8  (减去Type+Seq+Timestamp+CRC16)
  4. 读取Type(1B)、Seq(1B)、Timestamp(4B，小端uint32_t)、Payload(payload_len B)
  5. 读取CRC16(2B，小端序): crc_recv = CRC_L | (CRC_H << 8)
  6. 校验CRC: 对 Length+Type+Seq+Timestamp+Payload 计算CRC16，与crc_recv比对
  7. 校验帧尾: 下两个字节应为 0x0D 0x0A
  8. 根据Type解析Payload(见下文)

  注意: 如果CRC校验失败或帧尾不匹配，丢弃该帧，重新搜索帧头。

        distance = struct.unpack_from('<f', payload, offset + 4)[0]
        points.append((angle, distance))


四、帧总长度速查
────────────────────────────────────────────────────────────

  Type  内容        Payload  帧总长度
  ────  ──────      ───────  ────────
  1     瞬时速度    16B      2+2+1+1+4+16+2+2 = 30B
  2     总脉冲      16B      2+2+1+1+4+16+2+2 = 30B
  3     IMU         24B      2+2+1+1+4+24+2+2 = 38B
  4     雷达        2+8N B   2+2+1+1+4+(2+8N)+2+2 = 14+8N B
      (N=点数，最大512个点，最大帧长 = 14+8×512 = 4110B)


五、Timestamp 打戳时机总结
────────────────────────────────────────────────────────────

  Type  数据        打戳时机                          main.c代码
  ────  ──────      ──────────────────────────────    ──────────
  1     瞬时速度    PID周期读取编码器数据的瞬间        enc_ts = HAL_GetTick()
  2     总脉冲      同上(与Type=1同一时刻)            enc_ts = HAL_GetTick()
  3     IMU         imu->data_ready 为真的瞬间         imu_ts = HAL_GetTick()
  4     雷达        frame->data_ready 为真的瞬间       lidar_ts = HAL_GetTick()

  关键: 时间戳由调用方在数据就绪的第一时间获取，而非组帧发送时。
        这样不同传感器的Timestamp能真实反映各自的采集时刻，
        便于上层建图时做时间对齐和插值。


六、ESP32端 Python 伪代码 —— 完整解帧
────────────────────────────────────────────────────────────

  import struct

  def crc16_modbus(data):
      crc = 0xFFFF
      for b in data:
          crc ^= b
          for _ in range(8):
              if crc & 1:
                  crc = (crc >> 1) ^ 0xA001
              else:
                  crc >>= 1
      return crc

  def parse_frame(buf):
      # 1. 找帧头
      if len(buf) < 13:
          return None
      if buf[0] != 0xAA or buf[1] != 0x55:
          return None

      # 2. 读Length (2字节小端序)
      length = buf[2] | (buf[3] << 8)
      if length < 8:             # 防御性检查: 最小length=8 (0 payload)
          return None            # 非法帧
      payload_len = length - 8   # 减去 Type(1) + Seq(1) + Timestamp(4) + CRC(2)
      total_len = 2 + 2 + length + 2  # header + length字段 + (type+seq+ts+payload+crc) + tail
      if len(buf) < total_len:
          return None  # 帧不完整

      # 3. 提取字段
      type_val   = buf[4]
      seq        = buf[5]
      timestamp  = struct.unpack_from('<I', buf, 6)[0]   # uint32_t 毫秒时间戳(数据就绪瞬间)
      payload    = buf[10 : 10 + payload_len]
      crc_recv   = buf[10 + payload_len] | (buf[10 + payload_len + 1] << 8)
      tail       = buf[10 + payload_len + 2 : 10 + payload_len + 4]

      # 4. 校验帧尾
      if tail != b'\x0d\x0a':
          return None

      # 5. 校验CRC (从Length到Payload末尾)
      crc_calc = crc16_modbus(buf[2 : 10 + payload_len])
      if crc_calc != crc_recv:
          return None

      # 6. 按Type解析Payload
      if type_val == 1:
          speeds = struct.unpack_from('<4f', payload)
          return {'type': 'speed', 'seq': seq, 'ts': timestamp, 'data': speeds}
      elif type_val == 2:
          pulses = struct.unpack_from('<4i', payload)
          return {'type': 'pulse', 'seq': seq, 'ts': timestamp, 'data': pulses}
      elif type_val == 3:
          ax, ay, az, gx, gy, gz = struct.unpack_from('<6f', payload)
          return {'type': 'imu', 'seq': seq, 'ts': timestamp, 'data': (ax,ay,az,gx,gy,gz)}
      elif type_val == 4:
          point_num = struct.unpack_from('<H', payload, 0)[0]
          points = []
          for k in range(point_num):
              angle, dist = struct.unpack_from('<ff', payload, 2 + k*8)
              points.append((angle, dist))
          return {'type': 'lidar', 'seq': seq, 'ts': timestamp, 'data': points}
      else:
          return None
